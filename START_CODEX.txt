SJ MIRROR — INÍCIO COM CODEX CLI

1. Crie uma pasta:

mkdir SJMirror
cd SJMirror

2. Copie para essa pasta:
   - PLAN.md
   - AGENTS.md

3. Opcionalmente inicialize o Git:

git init

4. Abra o Codex:

codex

5. Primeiro prompt:

Leia AGENTS.md e PLAN.md.

Implemente SOMENTE a Fase 0 do PLAN.md.

Crie o bootstrap do projeto SJ Mirror usando C#, .NET 10, WPF e xUnit.

Não implemente ADB.
Não implemente scrcpy.
Não implemente streaming.

Ao finalizar, execute dotnet build e dotnet test.
Corrija erros causados pelas alterações.
Mostre um resumo e não avance para a Fase 1.

6. Depois de validar a primeira fase, use:

Leia AGENTS.md e PLAN.md.
Implemente SOMENTE a Fase 1.
Execute build e testes.
Não avance para a próxima fase.
